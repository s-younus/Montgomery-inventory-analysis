# Montgomery Fleet Equipment Inventory Analysis

## Project Overview

This project analyzes fleet equipment inventory data for a local government office. The workbook was previously imported, cleaned, and prepared for analysis. As a Junior Data Analyst, the goal of this assignment was to organize the cleaned inventory data, calculate summary statistics, and use Pivot Tables to analyze equipment counts by department and equipment class.

The final Excel workbook is prepared for future dashboard creation and a data findings report.

## File Included

- `Montgomery_Fleet_Equipment_Inventory_FA_PART_2_END.xlsx`  
  Final cleaned and analyzed Excel workbook containing formatted data and Pivot Table worksheets.

## Objectives

The main objectives of this project were to:

- Format the cleaned fleet inventory data as an Excel table
- Use AutoSum to calculate summary values for column C
- Create Pivot Tables to summarize equipment count by department
- Sort Pivot Table results in descending order by equipment count
- Build additional Pivot Tables for deeper analysis by department and equipment class
- Organize the final workbook for submission and future reporting

## Tasks Completed

### 1. Data Formatting

The main fleet inventory worksheet was formatted as an Excel table using the **Format as Table** option. This makes the dataset easier to filter, sort, and analyze.

### 2. AutoSum Calculations

AutoSum was used on column C to calculate the following values:

- Sum
- Average
- Minimum
- Maximum
- Count

These calculations helped provide a quick statistical overview of the selected numeric field.

### 3. Pivot Table 1

A Pivot Table was created on a new worksheet named **Pivot Table 1**.

The Pivot Table displays:

- **Rows:** Department
- **Values:** Sum of Equipment Count

This table shows the total equipment count by department and is sorted in descending order.

### 4. Pivot Table 2

A second Pivot Table was created on a worksheet named **Pivot Table 2**.

This Pivot Table displays:

- **Rows:** Department
- **Sub-row:** Equipment Class
- **Values:** Sum of Equipment Count

This view allows analysis of vehicle or equipment types within each department. The table was collapsed so that only the top department, **Transportation**, remains expanded.

### 5. Pivot Table 3

A third Pivot Table was created on a worksheet named **Pivot Table 3**.

This Pivot Table displays:

- **Rows:** Equipment Class
- **Sub-row:** Department
- **Values:** Sum of Equipment Count

This view allows analysis of departments grouped under each equipment class. The table was collapsed so that only the top equipment class, **CUV**, remains expanded.
